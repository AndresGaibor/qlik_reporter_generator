# Despliegue

Para producción consulta [Levantar Qlik Reportes Creator desde cero](../despliegue/LEVANTAR-DESDE-CERO.md).

Para desarrollo local usa [Guía de arranque local](guia-arranque-local.md). En Docker Compose las migraciones se aplican con el servicio `migrate`; `bun run db:migrate` se reserva para el flujo local con Bun cuando corresponda.
