# Métricas de Éxito — Qlik Automate Creator

## Propuesta inicial

| Métrica | Definición | Meta |
|---------|------------|------|
| Tiempo de creación | Tiempo promedio desde seleccionar dataflow/tabla hasta automatización activa | < 5 min |
| Tasa de uso | % de usuarios activos que crean al menos 1 automatización / mes | > 70% |
| Tasa de éxito | % de ejecuciones completadas sin error | > 95% |
| Adopción de schedule | % de automatizaciones usando editor Qlik vs cron propio | Pendiente definir |

---

## Métricas operativas

| Métrica | Definición |
|---------|------------|
| # de automatizaciones creadas / mes | Volumen de uso |
| # de ejecuciones / mes | Frecuencia de uso |
| Tiempo medio de ejecución | Performance de las automatizaciones |
| # de errores por mes | Salud del sistema |
